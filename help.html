一、先认识首页

本站按“基础篇 → 强化讲义 → 习题集”组织，另有一组学习工具。

  • 基础篇：李永乐《复习全书·基础篇》数二内容。高数为第 1、2、3、5、6、8 章，线代为第 1–6 章；每章 = 正文逐页精讲 + 零基础进阶题。
  • 强化讲义：武忠祥高数讲义、线代讲义。
  • 习题集：660 题、880 题，均可看原页、逐题做。
  • 工具：公式手册、题型方法库、公式闪卡、模拟测验、错题本、今日复习、考点速查。
数二不考：概率、无穷级数、向量代数与空间解析几何、三重积分/曲线曲面积分、方向导数与梯度、经济应用、差分方程。看到相关内容可直接跳过。
公式由 MathJax 加载，首次打开需联网；建议使用最新版 Chrome / Edge / Safari。

二、一章怎么学（核心流程）

  1. 看目录：章页左侧是本章目录，点节跳转。
  2. 读精讲：每节按“原书原页 → 逐页精讲”排列，先看原页，再看精讲。
  3. 做标记：每节标题下有 ✅ 已读 / ❓ 不懂。已读会计入首页进度并安排间隔复习；不懂会进入错题本“章节不懂”。
  4. 做本节自测：点选项立即判分，答错自动进错题本。
  5. 做进阶题：先自己做；卡住先展开「💡 思路提示」；仍不会再点「显示答案与解答」；最后自评对错。
  6. 当天复盘：打开「📕 错题本」与「🔁 今日复习」，把不会的标出来。
原则：先想 → 再看提示 → 最后看答案。不要一上来就展开解答。

三、进阶题怎么用最有效

  • 进阶题按章附在正文后面，题号为站内重编号；原页仅供对照。
  • 每题上方有「🏷 考点」，先判断在考什么，再动笔。
  • 选择题点选项直接判分；解答/证明题点「显示答案与解答」后，用「我做对了 / 我做错了」自评。
  • 微分方程章已删去数三的差分方程/经济应用题；原页里若看到，跳过即可。
  • 想专项刷题，用「🎯 考点速查」按考点筛选，例如“洛必达”“极坐标”“相似”“正定”，点条目直达题目。

四、错题本与今日复习

  • 错题本自动收集：本节自测错题、进阶题做错、标记“不懂”的章节。
  • 每题可点「✓ 已弄懂，移除」；进阶题错题可直接跳回题目。
  • 今日复习按间隔重复安排；每次选「不会 / 模糊 / 会」，系统自动排下次复习时间。
  • 错题本里的“考点”行可帮你判断是概念不清还是计算失误。

五、手机 / iPad

  • 长公式可在公式块内左右滑动（页面顶部有提示）。
  • 章节筛选按钮可左右滑动。
  • 右下角 ✏️ 草稿纸 可手写演算（支持 Apple Pencil 压感），💾 备份 可导出学习数据。
  • 学习数据存在本机浏览器；换设备、清缓存会丢失，重要进度请定期备份。

六、建议节奏（一轮基础）

  • 每天 1 节（约 1.5–2 小时）：精讲 40 分钟 → 自测 20 分钟 → 进阶题 40 分钟 → 标记/复盘 10 分钟。
  • 每周日：清一次错题本；用「考点速查」刷本周薄弱考点；用「公式闪卡」过一遍公式。
  • 基础篇过完后，再进入强化讲义 + 660/880。
数学二真题：进入「📄 数学二真题」，近 15 年（2012–2026）共 339 题。建议先限时 180 分钟整套作答，再逐题核对；选择题自动判分，填空/解答自评，错题会进入错题本。页面右上角有「🖨 打印试卷 / 🖨 打印答案解析」，在浏览器打印对话框中选择“另存为 PDF”即可导出；试卷模式不含答案与考点提示。
遇到显示异常：先刷新；仍异常请把“章节 + 页码”发给老师。

七、冲 120 分要刷多少题

目标 120/150：选填最多错 2 个（70+/80），解答题拿 50+/70。关键不是题量最大，而是选填稳、中档题不丢、错题二刷。

阶段建议题量说明
基础基础篇 191 + 自测 98 + 660 选择填空 520660 全部做，练选填速度与准确率
强化880 数二 500–600 道高数重点章 + 线代全部；不必 877 全刷
真题近 15–20 年数二真题（约 350–450 题）套卷限时，错题二刷
模拟10–15 套（约 230–350 题）冲刺期用，练时间分配
错题上述错题 二刷 2–3 遍比做新题更重要

合计约 1,800–2,200 道（含二刷约 2,500–3,000 题次）。基础较好可减到 1,200–1,500 道，但真题和错题二刷不能省。

分数拆解

  • 选择 + 填空 80 分：最多错 2 个，拿 70+。
  • 解答题 70 分：前 4 题基本满分，后 2 题拿部分，拿 50+。

质量指标（比题量更重要）

  • 选填限时 50–60 分钟，正确率 ≥ 85%。
  • 真题套卷稳定 115–125，再冲 120+。
  • 错题二刷正确率 ≥ 90%；同类计算错误不超过 2 次。
  • 积分、行列式、矩阵运算不跳步，每天保持 20–30 分钟计算训练。

避坑

  • 不要只刷 880 不做真题；真题才是 120 分的标尺。
  • 不要追求“刷了几遍”，要记录错题原因（概念 / 计算 / 审题）。
  • 基础一般按上表执行，约 6–8 个月；基础较好可压缩到 4–5 个月。
