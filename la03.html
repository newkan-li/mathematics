知识结构网络图 · 基本内容与重要结论

📌 本页要点
  • n维向量核心：线性组合、线性相关与线性无关的判定
  • 向量组秩与矩阵秩等价，是解方程组与判定的关键
  • 线性表出与方程组解、向量组等价可相互转化
  • 考研重点：含参向量组相关性讨论与极大无关组
📐 核心公式
$$\alpha_1,\cdots,\alpha_s\text{线性相关}\Leftrightarrow \exists k_i\text{不全为0},\sum_{i=1}^s k_i\alpha_i=0$$
$$\alpha_1,\cdots,\alpha_s\text{线性无关}\Leftrightarrow \sum_{i=1}^s k_i\alpha_i=0\Rightarrow k_i=0$$
$$r(\alpha_1,\cdots,\alpha_s)=r(A),\ A=(\alpha_1,\cdots,\alpha_s)$$
$$\beta\text{可由}\alpha_1,\cdots,\alpha_s\text{线性表出}\Leftrightarrow r(A)=r(A,\beta)$$
$$\text{若}\alpha_1,\cdots,\alpha_s\text{线性无关，则其任意部分组线性无关}$$
例：设向量组 $\alpha_1=(1,1,1)^T,\ \alpha_2=(1,2,3)^T,\ \alpha_3=(1,3,a)^T$。问 $a$ 取何值时，$\alpha_1,\alpha_2,\alpha_3$ 线性相关？并求此时的一个极大无关组。
解答
令 $A=(\alpha_1,\alpha_2,\alpha_3)$，则 $$|A|=\begin{vmatrix}1&1&1\\1&2&3\\1&3&a\end{vmatrix} =\begin{vmatrix}1&1&1\\0&1&2\\0&2&a-1\end{vmatrix} =a-5.$$ 所以当 $a=5$ 时，$|A|=0$，向量组线性相关。 当 $a=5$ 时， $$A=\begin{pmatrix}1&1&1\\1&2&3\\1&3&5\end{pmatrix} \to\begin{pmatrix}1&1&1\\0&1&2\\0&0&0\end{pmatrix}.$$ 因此 $r(\alpha_1,\alpha_2,\alpha_3)=2$，且 $\alpha_1,\alpha_2$ 线性无关，故一个极大无关组为 $\alpha_1,\alpha_2$。

典型例题分析选讲

📌 本页要点
  • 向量组线性相关性与秩的判定是核心考点
  • 掌握线性表示与方程组解的关系
  • 会求向量组的秩与最大无关组
  • 理解向量空间基与维数的概念
📐 核心公式
$$\alpha_1,\alpha_2,\cdots,\alpha_s \text{ 线性相关} \Leftrightarrow \exists k_i \text{ 不全为0}, \sum_{i=1}^s k_i\alpha_i=0$$
$$\text{向量组 } A \text{ 可由 } B \text{ 线性表示} \Leftrightarrow r(B)=r(B,A)$$
$$r(\alpha_1,\alpha_2,\cdots,\alpha_s) = \text{矩阵 } (\alpha_1,\alpha_2,\cdots,\alpha_s) \text{ 的秩}$$
$$\text{若 } \alpha_1,\cdots,\alpha_r \text{ 线性无关，且 } \alpha_{r+1} \text{ 可由其表示，则 } r(\alpha_1,\cdots,\alpha_{r+1})=r$$
例：设向量组 $\alpha_1=(1,2,3)^T,\ \alpha_2=(2,3,4)^T,\ \alpha_3=(3,4,5)^T$，求该向量组的秩和一个最大无关组。
解答
构造矩阵 $A=(\alpha_1,\alpha_2,\alpha_3)=\begin{pmatrix}1&2&3\\2&3&4\\3&4&5\end{pmatrix}$。\ 对 $A$ 作初等行变换：\ $\begin{pmatrix}1&2&3\\2&3&4\\3&4&5\end{pmatrix}\xrightarrow{\substack{r_2-2r_1\\r_3-3r_1}}\begin{pmatrix}1&2&3\\0&-1&-2\\0&-2&-4\end{pmatrix}\xrightarrow{r_3-2r_2}\begin{pmatrix}1&2&3\\0&-1&-2\\0&0&0\end{pmatrix}$。\ 非零行数为2，故 $r(\alpha_1,\alpha_2,\alpha_3)=2$。\ 取非零行首元所在列对应的原向量 $\alpha_1,\alpha_2$，它们线性无关，构成一个最大无关组。

练习题精选

📌 本页要点
  • 向量组线性相关⇔齐次方程组有非零解
  • 向量组秩=极大无关组所含向量个数
  • 矩阵秩=行秩=列秩，初等变换不改变秩
  • 线性表示⇔增广矩阵秩等于系数矩阵秩
📐 核心公式
$$\alpha_1,\alpha_2,\cdots,\alpha_s\text{线性相关}\Leftrightarrow r(\alpha_1,\alpha_2,\cdots,\alpha_s)
$$r(AB)\leq\min\{r(A),r(B)\}$$
$$r(A+B)\leq r(A)+r(B)$$
$$\beta\text{可由}\alpha_1,\cdots,\alpha_s\text{线性表示}\Leftrightarrow r(\alpha_1,\cdots,\alpha_s)=r(\alpha_1,\cdots,\alpha_s,\beta)$$
例：设向量组 $\alpha_1=(1,2,3)^T,\ \alpha_2=(2,3,4)^T,\ \alpha_3=(3,4,5)^T$，判断其线性相关性，并求其秩与一个极大无关组。
解答
令 $A=(\alpha_1,\alpha_2,\alpha_3)$，对 $A$ 作初等行变换：\[ A=\begin{pmatrix}1&2&3\\2&3&4\\3&4&5\end{pmatrix}\xrightarrow{\substack{r_2-2r_1\\ r_3-3r_1}}\begin{pmatrix}1&2&3\\0&-1&-2\\0&-2&-4\end{pmatrix}\xrightarrow{r_3-2r_2}\begin{pmatrix}1&2&3\\0&-1&-2\\0&0&0\end{pmatrix}.\] 可见 $r(A)=2<3$，故 $\alpha_1,\alpha_2,\alpha_3$ 线性相关。秩为 $2$，一个极大无关组为 $\alpha_1,\alpha_2$（也可取 $\alpha_1,\alpha_3$ 或 $\alpha_2,\alpha_3$）。
